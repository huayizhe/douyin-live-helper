# 抖音关注直播插件资源监控优化方案

## 一、当前资源使用分析

### 1. 直播列表加载
- **时机**：打开关注直播窗口时
- **资源**：获取关注主播的直播列表数据
- **包含**：主播信息、房间信息、封面图URL等

### 2. 预加载系统（PreloadManager）
- **时机**：当直播卡片进入视口或接近视口时（视口1.5倍范围内）
- **资源**：
  - HLS直播流（限制缓存大小：最多5个直播流）
  - 视频元素（隐藏的video标签）
  - 每个直播流的HLS实例
- **清理机制**：
  - 超过最大缓存数量时，删除最旧的缓存
  - 18秒自动更新预加载内容

### 3. 预览系统（PreviewHandler）
- **时机**：鼠标悬停在直播卡片上800ms后
- **资源**：
  - 视频元素
  - HLS实例
  - 最后一帧截图（JPEG格式，压缩率0.8）
- **内存监控**：
  - 正常水平：1GB
  - 警告水平：1.5GB
  - 临界水平：2GB
- **清理机制**：
  - 正常清理：保留最近5个
  - 警告清理：保留最近3个
  - 紧急清理：只保留当前播放的

### 4. 本地存储使用
- **localStorage**：
  - `webid`
  - `msToken`
  - `X-Bogus`
  - 预览截图（`preview_${roomUrl}`）
  - 主播配置（`floatingTextConfig_${secUid}`）

### 5. 可能的资源泄露点
- 未及时清理的video元素
- 未销毁的HLS实例
- 未清理的预览截图缓存
- 过期的预加载内容
- 未释放的内存监控定时器

### 6. 性能优化建议
1. **预加载优化**：
   - 根据网络状况动态调整预加载数量
   - 低网速时降低预加载质量
2. **缓存优化**：
   - 定期清理过期的localStorage内容
   - 限制预览截图的存储时间
3. **内存管理**：
   - 更频繁地检查和清理未使用的资源
   - 降低预加载视频的缓冲区大小
4. **资源释放**：
   - 确保在切换页面时完全清理资源
   - 实现完整的资源释放机制
