# 收款发卡手册

面向运营者（你本人）。当前为**半自动模式**：用户付款后你手动签发许可证发给对方。跑通有量后再上爱发电自动发卡（见《服务器部署手册》）。

---

## 一、准备工作（一次性）

1. 安装 Node.js（≥ 16）。
2. 在项目根目录生成密钥对（**只做一次**）：
   ```
   node tools/keygen-pair.js
   ```
   - 私钥保存在 `tools/private-key.json`（已被 .gitignore 忽略）。**务必备份、绝不可外泄或发给任何人**——它能签发无限许可证。
   - 公钥已自动写入 `js/license.js`。之后执行 `npm run release` 让插件包生效。
3. 准备收款码：微信 / 支付宝个人收款码各一张。
4. 在 `js/constants.js` 的 `LICENSE` 里填写你的客服微信号（`CONTACT_WECHAT`），改完 `npm run release`。

价格对照：

| 套餐 | 价格 | 命令参数 |
|------|------|----------|
| 月付 | ¥12.9 | `--plan=month` |
| 年付 | ¥98 | `--plan=year` |
| 永久买断 | ¥258 | `--plan=lifetime` |

---

## 二、日常发卡流程（半自动）

1. 用户在插件里点「激活 PRO」→ 看到你的微信号 → 加你付款。
2. **核对到账**：确认金额对应套餐，留意备注。
3. **签发密钥**（按对方购买的套餐选一条）：
   ```
   node tools/issue-license.js --plan=month       # 月付
   node tools/issue-license.js --plan=year        # 年付
   node tools/issue-license.js --plan=lifetime    # 永久买断
   ```
4. 复制输出的整段许可证字符串，发回买家。
5. 买家在插件「激活 PRO」框粘贴 → 点激活 → 解锁。

### 话术模板（发给买家）
> 您的 PRO 许可证密钥如下（请妥善保管）：
> `<这里粘贴密钥>`
> 激活方法：打开抖音网页版 →「关注直播」→ 列表顶部点「激活 PRO」→ 粘贴密钥 → 点激活。

## 三、机器绑定（可选，防转卖）

默认签发的密钥**不绑设备**，任意设备可激活（体验顺滑，但可能被转发）。若担心一码多卖，可绑定设备：

1. 让买家在升级弹窗点「查看本机标识」，复制发给你。
2. 用该标识签发：
   ```
   node tools/issue-license.js --plan=year --machine=<买家的本机标识>
   ```
3. 此密钥只能在该设备激活，换设备会验签失败。

> 建议：起步用不绑定（省心），遇到明显倒卖再对高价套餐启用绑定。

---

## 四、售后处理

- **换设备**：用户在旧设备升级弹窗点「解除本设备激活」后，同一密钥可在新设备激活（未绑定的密钥本就随意激活；已绑定的需你用新标识重新签发）。
- **续费**：到期后重新签发一条新密钥发给用户即可（旧密钥到期自动失效）。
- **退款**：未绑定密钥无法远程吊销（阶段一离线特性）；如需可吊销能力，启用阶段二联网模式。
- **自定义时长**：`--days=N`，例如试用 7 天 `--plan=month --days=7`。

---

## 五、升级到自动发卡（阶段二）

当订单量上来、手动发卡变累时，接入爱发电 Webhook 实现 24 小时自动发货。详见《服务器部署手册.md》。届时用户付款后系统自动签发、插件自动激活，无需你值守。
