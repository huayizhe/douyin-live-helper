# 运营手册（在线订阅）

接入在线支付后，发卡基本**全自动**：用户扫码付款 → 服务器签发 → 插件自动激活，你无需值守。本手册讲日常运营与异常处理。手动签发（`issue-license.js`）作为**服务器故障兜底**保留。

---

## 一、准备（一次性）

1. 生成密钥对（若尚未生成）：`node tools/keygen-pair.js`。私钥 `tools/private-key.json` 妥善备份、绝不外泄。
2. 部署许可证服务器并接入支付，见《服务器部署手册.md》。
3. 插件 `constants.js` 填 `LICENSE.SERVER`、客服微信，`npm run release`。

价格（在 `constants.js` 与 `server/config.js` 两处对齐）：

| 套餐 | 价格 | 时长 |
|------|------|------|
| 月付 | ¥12.9 | 30 天 |
| 年付 | ¥98 | 365 天 |
| 永久买断 | ¥258 | 永久 |

---

## 二、日常（全自动，无需操作）

用户在插件内：选套餐 → 点「立即开通」→ 扫码付款 → 插件轮询自动激活。订单记录在 `server/orders.json`（或 sqlite）。你只需保证服务器正常运行。

---

## 三、常见运营事项

- **查订单 / 对账**：查看 `server/orders.json`，或在支付宝/微信商户后台对账。
- **续费**：用户到期前插件会提示「续费」，点击走同样的购买流程；服务器自动把新到期**接续**在原到期之后（不浪费剩余天数）。
- **换设备**：用户在旧设备「管理授权」复制授权串，到新设备「激活 PRO」粘贴 → 插件自动调用换绑接口、绑定新设备。无需你介入。
- **退款**：在支付宝/微信商户后台操作退款。如需同时让授权失效，目前依赖到期自然失效；如要即时吊销，可在服务端加授权黑名单（后续迭代）。

---

## 四、服务器故障兜底（手动签发）

若服务器暂时不可用、用户已付款但没自动开通，可手动补发：

```
node tools/issue-license.js --plan=month                      # 月付
node tools/issue-license.js --plan=year                       # 年付
node tools/issue-license.js --plan=lifetime                   # 永久
node tools/issue-license.js --plan=year --machine=<本机标识>  # 绑定指定设备
```

把输出的授权串发给用户，让其在「激活 PRO」→「已有激活码？手动激活」里粘贴。话术：
> 您的 PRO 授权如下，请在插件「激活 PRO」→「手动激活」粘贴：
> `<授权串>`

---

## 五、安全红线

- 私钥 `tools/private-key.json` / 服务器 `.env` 绝不外泄、绝不提交版本库。
- 它能签发无限授权，泄露等于授权体系作废，需重签全部。
