# 插件配置与测试手册

面向开发/发布。涵盖授权配置、构建、加载、测试、打包发布。

---

## 一、构建铁律

插件实际加载的是 `dist/`（rollup 编译产物）。**修改 `js/` 下任何源码后，必须执行 `npm run build`（或 `npm run release`）才会生效**，否则改动不进 `dist/`。这是最容易踩的坑。

- `npm run build`：仅编译到 `dist/`。
- `npm run release`：编译 + 同步发布包到 `douyin_live_helper_plugin/`（对外分发用这个）。

---

## 二、授权配置（一次性）

1. 生成密钥对（首次）：
   ```
   node tools/keygen-pair.js
   ```
   - 公钥自动写入 `js/license.js` 的 `_PK`；私钥存 `tools/private-key.json`（勿外泄、勿提交）。
2. 在 `js/constants.js` 的 `LICENSE` 配置：
   - `CONTACT_WECHAT`：客服微信号（手动兜底/未配服务器时显示）。
   - `PRICING`：三档套餐，`amount`(分)/`days`(时长)/`price`/`note`，需与 `server/config.js` 对齐。
   - `BUY_URL`：可选购买页。
   - `SERVER`：许可证服务器地址。**开发自测填 `http://localhost:3000`；生产填 HTTPS 域名**；留空则降级为"仅手动激活码 + 联系微信"。
3. `manifest.json` 的 `host_permissions` 把 `https://your-license-server.com/*` 改成你的服务器域名（开发期 `http://localhost:3000/*` 已内置）。
4. 改完执行 `npm run release`。

> 在线支付需服务器；`manifest.json` 权限保持 `activeTab` + `storage`，并新增服务器域名到 `host_permissions`。

---

## 三、加载到浏览器

1. 打开 `chrome://extensions/`（或 `edge://extensions/`）。
2. 开启「开发者模式」。
3. 点「加载已解压的扩展程序」→ 选含 `manifest.json` 的目录：
   - 开发期：项目根目录。
   - 发布期：发布包 `douyin_live_helper_plugin/`。
4. 打开 `https://www.douyin.com` 验证。

## 四、测试用例

### 0. 在线购买（mock 本地联调）
- 起本地 server：`cd server`，PowerShell 执行 `$env:PAY_CHANNEL='mock'; node index.js`。
- `constants.js` 的 `SERVER` 设 `http://localhost:3000`，`npm run build`，重新加载扩展。
- 升级弹窗：套餐卡点击应单选高亮（默认年付）；点「立即开通」→ 弹出二维码视图。
- 模拟付款：查 `server/orders.json` 拿到 `orderId`，执行
  `curl -X POST localhost:3000/api/mock/pay -H "Content-Type: application/json" -d "{\"orderId\":\"<orderId>\"}"`。
- 插件应在 ~2.5s 内轮询到成功、自动激活、徽章变 ✓ PRO、功能解锁。

### 1. 免费态（未激活）
- 直播列表顶部应显示「激活 PRO」徽章。
- 点**多路对比**（勾 2 个主播后点对比预览）/ 大屏**录制**按钮 / **氛围词条**配置或开关 → 应弹出权益对比升级页，功能被拦截。
- **三联屏镜像**、**特别关心**（可加任意多个）、**资源监控** → 应正常可用，不拦截。

### 2. 激活态
- 签发测试密钥：`node tools/issue-license.js --plan=month`。
- 升级弹窗粘贴密钥 → 点激活 → 提示成功，徽章变「✓ PRO」。
- 上述被锁功能（对比/录制/词条）应全部解锁可用。
- 点「✓ PRO」徽章 → 显示套餐与到期日；可「解除本设备激活」。

### 3. 防伪
- 把已激活的密钥手动改掉任意字符再激活 → 应提示无效、保持免费态。
- 用 `--days=-1` 或已过期 `e` 签发 → 激活应被拒。
- 机器绑定：`--machine=<本机标识>` 签发后，在另一浏览器配置（不同 machineId）激活 → 应被拒。

> 加密闭环已通过自测（正常通过 / 篡改被拒 / 伪造 payload 被拒 / 过期被拒 / 绑定生效）。

### 4. 切换账号测试免费/PRO
- 解除激活后刷新页面，应回到免费态（被锁功能重新弹升级页）。

## 五、发布打包

1. 更新版本号：`manifest.json` 与 `package.json`（保持一致）。
2. 同步更新 `README.md` / `CHANGELOG.md` / `DEV.md`。
3. `npm run release` 生成发布包 `douyin_live_helper_plugin/`。
4. 该目录打包 ZIP 提交 Chrome / Edge 商店，或直接分发给用户解压加载。

> 注意：`tools/`、`server/`、`docs/`、`private-key.json` **不进发布包**（它们是你本地的签发/运营文件，release 脚本只复制 manifest/dist/lib/css/icons/README）。
