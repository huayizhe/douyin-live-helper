# 服务器部署手册（阶段二：爱发电自动发卡）

> ⚠️ 本手册针对**阶段二**——把半自动发卡升级为 24 小时自动发货。当前阶段一为离线半自动，**无需服务器**；待订单量上来、需要自动发货时再按本手册实施。届时新增 `server/` 目录代码。

---

## 一、整体链路

```
用户在插件点「购买」
  → 打开爱发电商品链接（提示在备注粘贴“本机标识/取件码”）
  → 用户用微信/支付宝付款
  → 爱发电 Webhook 回调你的服务器
  → 服务器用私钥签发许可证，按取件码绑定
  → 插件轮询 /api/claim?code=取件码 → 拿到许可证 → 自动激活
```

爱发电 Webhook **没有自定义订单号字段**，因此用**备注 remark**（取件码）来关联机器与订单。

---

## 二、环境要求

- Node.js ≥ 18
- 一台可公网访问的服务器
- 一个域名 + HTTPS 证书（爱发电 Webhook 要求 HTTPS）
- 爱发电创作者账号（个人实名即可），并已创建商品

---

## 三、安装与配置

1. 进入服务端目录安装依赖：
   ```
   cd server
   npm install
   ```
2. 复用阶段一的私钥：把 `tools/private-key.json` 的私钥配置到服务器 `.env`（服务器与命令行工具共用同一密钥，签发的许可证才能被插件公钥验签）。
3. 配置 `server/.env`（该文件已被 .gitignore 忽略）：
   ```
   PRIVATE_KEY_JWK={...粘贴 private-key.json 内容（单行）...}
   PORT=3000
   AFDIAN_USER_ID=你的爱发电user_id
   AFDIAN_TOKEN=你的爱发电token
   ```

---

## 四、启动

- 开发自测：
  ```
  node index.js
  ```
- 生产（推荐 pm2 + Nginx 反代 443）：
  ```
  pm2 start index.js --name dylh-license
  ```
  Nginx 示例：
  ```nginx
  server {
      listen 443 ssl;
      server_name lic.yourdomain.com;
      ssl_certificate     /path/fullchain.pem;
      ssl_certificate_key /path/privkey.pem;
      location / { proxy_pass http://127.0.0.1:3000; }
  }
  ```

---

## 五、爱发电后台配置

1. 创建三个商品对应月/年/买断；设为隐藏商品，仅通过插件生成的链接售卖。
2. 开发者设置里，Webhook 通知 URL 填：
   ```
   https://lic.yourdomain.com/afdian/webhook
   ```
3. 记录 `user_id` 和 `token` 填入 `.env`。
4. 爱发电 API 签名规则：`sign = md5(token + 'params' + params + 'ts' + ts + 'user_id' + user_id)`，主动查单接口 `https://afdian.net/api/open/query-order`（用于 Webhook 漏推时对账补偿）。

---

## 六、测试

1. 健康检查：
   ```
   curl https://lic.yourdomain.com/health
   ```
2. 模拟爱发电 Webhook（断言返回 `{"ec":200,"em":""}` 且库中生成许可证）：
   ```
   curl -X POST https://lic.yourdomain.com/afdian/webhook \
     -H "Content-Type: application/json" \
     -d '{"ec":200,"em":"ok","data":{"type":"order","order":{"out_trade_no":"T1","status":2,"remark":"<取件码>","plan_id":"...","total_amount":"98.00"}}}'
   ```
3. 验证领取接口返回许可证：
   ```
   curl "https://lic.yourdomain.com/api/claim?code=<取件码>"
   ```
4. 在插件里走完整链路：点购买 → 备注取件码 → 付款 → 插件轮询自动激活。

---

## 七、安全注意

- `private-key.json` / `.env` 中的私钥是命脉，泄露需重新签发全部许可证。绝不提交版本库。
- 数据库文件 `server/*.db` 已被 .gitignore 忽略。
- 为离线滥用设宽限期（参考 `constants.js` 的 `GRACE_PERIOD`），Token 到期后插件后台静默续期。
