# 服务器部署手册（在线订阅 · 官方支付）

把"扫码付款 → 自动开通"跑起来需要：一台服务器 + 域名 + HTTPS + 支付商户号。本手册从零到上线。

> 开发期可先用 **mock 渠道**在本地把全链路跑通（无需商户号），见末尾「本地 mock 自测」。

---

## 一、前置准备（并行去办）

1. **个体工商户营业执照**：线上即可办理（多数地区免费、无需实缴、无需实体店面）。微信支付必需；支付宝完整版也需要。
2. **微信支付商户号**：凭执照 + 一个该主体认证的**微信服务号**申请，开通 Native 支付，拿到 `mchid / APIv3 密钥 / 商户证书 / 证书序列号`。费率约 0.6%。
3. **支付宝商户（当面付）**：开放平台创建自研应用，开通「当面付」，配置应用私钥 + 支付宝公钥，拿到 `APPID`。无执照可先用基础版（限额版）。
4. **服务器 + 域名 + HTTPS**：一台云服务器，一个域名并完成**备案**（国内服务器必需，约一周），配置 HTTPS 证书。支付回调要求公网 HTTPS 可达。

---

## 二、安装

```
cd server
npm install
```

> `better-sqlite3` / `alipay-sdk` / `wechatpay-node-v3` 在 optionalDependencies；订单存储默认用零依赖 JSON 文件，真实支付时才需要对应 SDK（npm install 会自动装，装不上也不影响 mock）。

---

## 三、配置 `.env`（由 `.env.example` 复制）

```
# 私钥（与 tools/private-key.json 相同 JWK，单行）。留空则自动回退读 ../tools/private-key.json
PRIVATE_KEY_JWK=
PAY_CHANNEL=alipay          # mock | alipay | wechat
PORT=3000
PUBLIC_BASE_URL=https://lic.yourdomain.com

# 支付宝当面付
ALIPAY_APP_ID=...
ALIPAY_PRIVATE_KEY=...      # 应用私钥
ALIPAY_PUBLIC_KEY=...       # 支付宝公钥

# 微信支付 Native v3
WX_APP_ID=...
WX_MCH_ID=...
WX_API_V3_KEY=...
WX_SERIAL_NO=...            # 商户证书序列号
WX_PRIVATE_KEY_PATH=./apiclient_key.pem
```

> 私钥必须与签发插件公钥的那把一致（即 `tools/private-key.json`），否则服务器签发的授权插件验不过。

---

## 四、启动

- 开发：`node index.js`
- 生产：`pm2 start index.js --name dylh-license`，前面用 Nginx 反代 443：
  ```nginx
  server {
      listen 443 ssl;
      server_name lic.yourdomain.com;
      ssl_certificate     /path/fullchain.pem;
      ssl_certificate_key /path/privkey.pem;
      location / { proxy_pass http://127.0.0.1:3000; }
  }
  ```

---

## 五、配置支付回调地址

在商户后台把异步通知地址填为：
- 支付宝：`https://lic.yourdomain.com/api/pay/notify/alipay`
- 微信：`https://lic.yourdomain.com/api/pay/notify/wechat`

（代码中下单时已自动带上 `notify_url`，商户后台保持一致即可。）

---

## 六、对接插件

1. 插件 [js/constants.js](../js/constants.js) 的 `LICENSE.SERVER` 填 `https://lic.yourdomain.com`。
2. [manifest.json](../manifest.json) 的 `host_permissions` 把 `https://your-license-server.com/*` 改成你的域名。
3. `npm run release` 重新打包插件。

---

## 七、测试

1. 健康检查：`curl https://lic.yourdomain.com/health` → `{"ok":true,"channel":"alipay"}`。
2. **支付宝沙箱**：开放平台沙箱环境配置后，用沙箱买家扫码完成一次下单→支付→回调→插件自动激活闭环，再切生产。
3. 真实小额自测：把某套餐临时改 1 分钱，真机扫码走通后改回。
4. 验证 `GET /api/order/status?orderId=...` 在支付后返回 `{status:'paid', license}`。

---

## 八、本地 mock 自测（无需商户号）

```
PAY_CHANNEL=mock node index.js
```
- `POST /api/order/create {plan,machineId}` → 拿到 `orderId`。
- `POST /api/mock/pay {orderId}`（模拟用户扫码付款）。
- `GET /api/order/status?orderId=` → 返回已签发的 license。
插件端把 `LICENSE.SERVER` 临时设为 `http://localhost:3000` 即可端到端联调。

---

## 九、安全与运维

- 私钥（`.env` / `tools/private-key.json`）是命脉，泄露需重签所有授权，绝不入库。
- 回调**必须验签**（代码已内置：支付宝公钥验签 / 微信平台证书验签）并校验金额，防伪造支付成功。
- 订单数据 `server/orders.json`（或 sqlite）定期备份。
- 退款在商户后台操作；如需吊销已发授权，可在服务端加黑名单（后续迭代）。
