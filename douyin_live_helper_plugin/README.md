一个浏览器扩展，让你更方便地查看和观看抖音关注主播的直播。

> 🚫 天然无广告，无打赏/消费引导弹窗；悬停即可预览，无需逐个点进直播间，清爽安静地浏览你关注的直播。

## 功能特点

- 🎯 在抖音网页版添加"关注直播"菜单，一键查看关注主播的直播列表（方块卡片式，数量再多也一目了然）
- 🔍 支持按主播昵称和直播标题搜索
- 📊 支持按观看人数排序
- ⭐ 支持"特别关心"标记主播，可单独筛选；数据用 `chrome.storage.sync` 存储，跨 www/live 子域、跨设备同步
- 👀 悬停预览直播内容，无需打开新标签页；移开鼠标后用最后一帧作为封面（带"已预览"标记），方便回看主播在播什么
- 🖼️ 点击直播截图进入大屏预览，点击标题跳转直播间
- 👤 点击主播头像跳转个人主页（带悬浮提示）
- 🖥️ 大屏预览：默认铺满整屏，支持浏览器全屏(F11)、ESC 分级退出
- 🔳 大屏三联屏模式：同一路画面镜像并排，零缝隙拼接（基于 captureStream 共享解码，不卡顿）
- 🆚 多路对比预览（PRO）：勾选最多 3 个**不同**直播间同屏对比，竖屏无黑边零缝隙拼接，每路可独立控声
- ⏺️ 直播录制（PRO）：大屏单路录制、对比单路录制、对比**合并录制**（三画面合成一个文件 + 混音）；高码率清晰画质，意外关闭/刷新自动保存已录内容
- 🔊 声音总开关（放音/静音）+ 全局音量记忆，悬浮预览与大屏预览声音统一、互相同步
- 💬 氛围词条（PRO）：支持为每个主播单独配置氛围词条（含 TTS 语音播报）
- 📈 内置资源监控，便于排查内存/实例占用
- 🌓 自动适配抖音深色/浅色模式
- 📺 智能检测连麦画面并自动调整显示比例
- ⌨️ 列表与各预览面板均支持 ESC 关闭

## 兼容浏览器

本插件基于 Chromium 内核扩展规范开发，支持以下国内常用浏览器：

- **已验证 / 推荐**：Google Chrome、Microsoft Edge（新版）、360 安全浏览器、360 极速浏览器、QQ 浏览器
- **同为 Chromium 内核、支持程度视版本而定**：夸克浏览器（电脑版）、搜狗高速浏览器、2345 加速浏览器、UC 浏览器（电脑版）

> 安装套路都一样：**进入浏览器"扩展管理"页 → 打开"开发者模式" → 点"加载已解压的扩展" → 选中含 `manifest.json` 的文件夹**（即发布包 `douyin_live_helper_plugin`）。各浏览器入口位置不同，下面逐个说明。

## 安装方法

> 安装前先把压缩包解压到一个固定文件夹，**安装后请勿删除或移动该文件夹**（移动后插件会失效）。

### Google Chrome
1. 点击右上角 **⋮（三个点菜单）→ 扩展程序 → 管理扩展程序**；也可直接在地址栏输入 `chrome://extensions/` 回车
2. 打开**页面右上角**的「开发者模式」开关
3. 点击左上角出现的「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹（里面要有 `manifest.json`）
5. 完成，点地址栏右侧的拼图图标即可看到本插件

### Microsoft Edge
1. 点击右上角 **⋯（三个点菜单）→ 扩展 → 管理扩展**；也可在地址栏输入 `edge://extensions/` 回车
2. 打开**左侧栏下方**的「开发人员模式」开关
3. 点击「**加载解压缩的扩展**」
4. 选择解压后的插件文件夹
5. 完成

### 360 安全浏览器 / 360 极速浏览器
1. 点击右上角 **☰（菜单）→ 更多工具 → 扩展中心**；也可在地址栏输入 `chrome://extensions/` 回车
2. 在扩展管理页打开**右上角**的「开发者模式」开关
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成（部分版本会弹窗，点"添加扩展"确认即可）

### QQ 浏览器
1. 点击右上角 **☰（菜单）→ 应用中心**，进入后点左侧「**我的应用 / 扩展管理**」；也可在地址栏输入 `chrome://extensions/` 回车
2. 打开页面**右上角**的「开发者模式」开关
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

### 夸克浏览器（电脑版）
1. 点击右上角 **☰（菜单）→ 扩展 / 扩展管理**；也可在地址栏输入 `chrome://extensions/` 回车
2. ⚠️「**开发者模式**」开关在扩展管理页的**左下角**——位置比较隐蔽，很多人第一次找不到，注意是**页面左下角**，不是右上角
3. 打开开发者模式后，点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

### 搜狗高速浏览器 / 2345 加速浏览器 / UC 浏览器（电脑版）
1. 打开浏览器菜单，找到「**扩展 / 扩展中心 / 更多工具 → 扩展程序**」；也可直接在地址栏输入 `chrome://extensions/` 回车
2. 在扩展管理页打开「**开发者模式**」开关（多数在右上角，少数在左下角，**找不到时上下角都看一下**）
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

> 小贴士：如果在菜单里找不到"扩展中心/扩展管理"，直接在地址栏输入 `chrome://extensions/` 回车，绝大多数 Chromium 浏览器都能打开扩展管理页。

## 使用方法

1. 安装插件后访问 [抖音网页版](https://www.douyin.com) 或 [抖音直播](https://live.douyin.com)
2. 在导航栏中找到"关注直播"菜单，点击查看所有正在直播的关注主播
3. 使用搜索框搜索主播或标题，点击"人气"按钮按观看人数排序
4. 点击卡片标题旁的爱心可将主播标记为"特别关心"，点击顶部筛选按钮只看特别关心
5. 鼠标悬停在直播卡片上可预览直播内容；点击画面进入大屏预览，点击标题进入直播间，点击头像进入主播主页
6. 顶部"放音/静音"按钮控制预览声音总开关，音量在大屏预览中可调并被记住
7. **大屏预览**：右下角控件可调音量、配置氛围词条、录制、进入浏览器全屏；可切换三联屏镜像
8. **多路对比**：在卡片右上角勾选 2-3 个主播，点顶部"对比预览"按钮，同屏对比不同直播间
   - 每路右下角可单独控声/调音量
   - 每路录制按钮单独录该路；右上角"合并录制"把三画面录成一个文件（与单路录制互斥）
   - 右上角全屏按钮进入浏览器全屏，ESC 先退全屏、再退对比
   - 顶部"清除已选"按钮可一键取消所有勾选；刷新列表也会自动清除勾选

## 注意事项

- 使用前请确保已登录抖音账号
- 仅支持抖音网页版，不支持手机版
- 录制保存为 webm 文件到浏览器默认下载目录；录制过程中关闭/刷新页面会尝试保存已录内容
- 多路对比为三路不同直播流同时解码，对机器性能有一定要求
- 如遇到问题请刷新页面或重新安装插件
- 连麦画面会自动调整以获得最佳观看体验
