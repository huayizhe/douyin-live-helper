# 抖音关注直播助手

极致提升查看已关注博主的直播观看体验

> ⚠️ **仅供学习使用，不可商用。**

## 优势一览

- **隐私无忧**：所有功能全部本地离线运行，不联网，不依赖云端，隐私安全无负担
- **超爽体验**：卡片式直播墙，数百主播同时展示，悬停即看内容，无需逐个点击打开
- **多路同看**：同时开启 2~3 个直播间，拼屏对比，画声独立控制，超爽体验
- **自由录制**：支持单路或合并录制（画面合成+混音），硬件编码省资源，意外关闭也能自动保存
- **特别关心**：特别关心标记、筛选，让你快速筛选最喜欢的主播

## 功能特点

- 🎯 在抖音网页版添加"关注直播"菜单，一键查看关注主播的直播列表（方块卡片式，数量再多也一目了然）
- 🔍 支持按主播昵称和直播标题搜索
- 📊 支持按观看人数排序
- ⭐ 支持"特别关心"标记主播，可单独筛选；数据用 `chrome.storage.local` 存储，按扩展隔离、跨 www/live 子域共享（注意：不跨设备同步、真卸载后会清空）
- 👀 悬停预览直播内容，无需打开新标签页；移开鼠标后用最后一帧作为封面（带"已预览"标记），方便回看主播在播什么
- 🪟 视口播放门控：仅当前视口里露出足够比例的卡片才播放循环视频，同屏播放路数受限，省解码省电
- ⚡ 首屏快速出画：视口内多路并行拉流；出画面后释放加载槽、稳播后再限流录成循环片段；滚动离屏卸 video、保留缓存再回来秒显
- 📊 本地观看统计：卡片显示「本周看 N 次」，排序支持「默认 / 人气 / 最常看」三态（纯本地、不上传）
- 💾 特别关心导入/导出：顶栏「资源/设置」→「数据备份」导出/导入 JSON，换设备或重装前先备份
- 💝 顶栏「赞赏/交流」：弹窗左右展示赞赏码与微信群码（均 CDN 托管，可随时更换）
- ⚙️ 直播墙性能可调：同一面板「插件设置」可改加载/录制并发、片段时长、清晰度档等；一键还原按本机核数推荐并发
- 🚀 大列表不卡：分批滚动加载，关注的在播主播数百上千也能流畅打开与搜索
- 🖼️ 点击直播截图进入大屏预览，点击标题跳转直播间
- 👤 点击主播头像跳转个人主页（带悬浮提示）
- 🖥️ 大屏预览：默认铺满整屏，支持浏览器全屏(F11)、ESC 分级退出
- 🔳 大屏三联屏模式：同一路画面镜像并排，零缝隙拼接（基于 captureStream 共享解码，不卡顿）
- 🆚 多路对比预览：勾选最多 3 个**不同**直播间同屏对比，竖屏无黑边零缝隙拼接，每路可独立控声
- ⏺️ 直播录制：大屏单路录制、对比单路录制、对比**合并录制**（三画面合成一个文件 + 混音）；高码率清晰画质，**H.264 硬件编码优先（省 CPU、支持多路同录）、不支持则回退 VP8**，意外关闭/刷新自动保存已录内容
- 🔊 声音总开关（放音/静音）+ 全局音量记忆，悬浮预览与大屏预览声音统一、互相同步
- 💬 氛围词条：支持为每个主播单独配置氛围词条（含 TTS 语音播报）
- 📈 内置资源监控（「资源/设置」面板），便于排查内存/实例占用
- 🌓 自动适配抖音深色/浅色模式
- 📺 智能检测连麦画面并自动调整显示比例
- ⌨️ 列表与各预览面板均支持 ESC 关闭

## 兼容浏览器

本插件基于 Chromium 内核扩展规范开发，支持以下国内常用浏览器：

- **已验证 / 推荐**：Google Chrome、Microsoft Edge（新版）、360 安全浏览器、360 极速浏览器、QQ 浏览器
- **同为 Chromium 内核、支持程度视版本而定**：夸克浏览器（电脑版）、搜狗高速浏览器、2345 加速浏览器、UC 浏览器（电脑版）

> 安装套路都一样：**进入浏览器"扩展管理"页 → 打开"开发者模式" → 点"加载已解压的扩展" → 选中含 `manifest.json` 的文件夹**（即发布包 `douyin_live_helper_plugin`）。各浏览器入口位置不同，下面逐个说明。

## 安装方法

> **下载最新安装包** [`抖音关注直播助手-v1.4.11.zip`](./抖音关注直播助手-v1.4.11.zip)（也可到 [Releases · 最新版](https://github.com/huayizhe/douyin-live-helper/releases/latest) 下载），解压后用浏览器「加载已解压的扩展」选中解压出的文件夹即可。

> 安装前请解压到一个固定文件夹，**安装后请勿删除或移动该文件夹**（移动后插件会失效）。

### Google Chrome
1. 点击右上角 **⋮（三个点菜单）→ 扩展程序 → 管理扩展程序**；也可直接在地址栏输入 `chrome://extensions/` 回车
2. 打开**页面右上角**的「开发者模式」开关
3. 点击左上角出现的「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹（里面要有 `manifest.json`）
5. 完成，点地址栏右侧的拼图图标即可看到本插件

### Microsoft Edge
1. 点击右上角 **⋯（三个点菜单）→ 扩展 → 管理扩展**；也可在地址栏输入 `edge://extensions/` 回车
2. 打开**左侧栏下方**的「开发人员模式」开关
3. 点击「**加载解压缩的扩展**」
4. 选择解压后的插件文件夹
5. 完成

### 360 安全浏览器 / 360 极速浏览器
1. 点击右上角 **☰（菜单）→ 更多工具 → 扩展中心**；也可在地址栏输入 `chrome://extensions/` 回车
2. 在扩展管理页打开**右上角**的「开发者模式」开关
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成（部分版本会弹窗，点"添加扩展"确认即可）

### QQ 浏览器
1. 点击右上角 **☰（菜单）→ 应用中心**，进入后点左侧「**我的应用 / 扩展管理**」；也可在地址栏输入 `chrome://extensions/` 回车
2. 打开页面**右上角**的「开发者模式」开关
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

### 夸克浏览器（电脑版）
1. 点击右上角 **☰（菜单）→ 扩展 / 扩展管理**；也可在地址栏输入 `chrome://extensions/` 回车
2. ⚠️「**开发者模式**」开关在扩展管理页的**左下角**——位置比较隐蔽，很多人第一次找不到，注意是**页面左下角**，不是右上角
3. 打开开发者模式后，点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

### 搜狗高速浏览器 / 2345 加速浏览器 / UC 浏览器（电脑版）
1. 打开浏览器菜单，找到「**扩展 / 扩展中心 / 更多工具 → 扩展程序**」；也可直接在地址栏输入 `chrome://extensions/` 回车
2. 在扩展管理页打开「**开发者模式**」开关（多数在右上角，少数在左下角，**找不到时上下角都看一下**）
3. 点击「**加载已解压的扩展程序**」
4. 选择解压后的插件文件夹
5. 完成

> 小贴士：如果在菜单里找不到"扩展中心/扩展管理"，直接在地址栏输入 `chrome://extensions/` 回车，绝大多数 Chromium 浏览器都能打开扩展管理页。

## 使用方法

1. 安装插件后访问 [抖音网页版](https://www.douyin.com) 或 [抖音直播](https://live.douyin.com)
2. 在导航栏中找到"关注直播"菜单，点击查看所有正在直播的关注主播
3. 使用搜索框搜索主播或标题，点击"人气"按钮按观看人数排序
4. 点击卡片标题旁的爱心可将主播标记为"特别关心"，点击顶部筛选按钮只看特别关心
5. 鼠标悬停在直播卡片上可预览直播内容；点击画面进入大屏预览，点击标题进入直播间，点击头像进入主播主页
6. 顶部"放音/静音"按钮控制预览声音总开关，音量在大屏预览中可调并被记住
7. **大屏预览**：右下角控件可调音量、配置氛围词条、录制、进入浏览器全屏；可切换三联屏镜像
8. **多路对比**：在卡片右上角勾选 2-3 个主播，点顶部「N 同时看」按钮（如「2 同时看」），同屏对比不同直播间
   - 每路右下角可单独控声/调音量
   - 每路录制按钮单独录该路；右上角"合并录制"把三画面录成一个文件（与单路录制互斥）
   - 右上角全屏按钮进入浏览器全屏，ESC 先退全屏、再退对比
   - 顶部"清除已选"按钮可一键取消所有勾选；刷新列表也会自动清除勾选
9. **大屏切清晰度**：右下角清晰度 chip → 弹出菜单与按钮等宽 → 选档后新画面出来再续播 1.5 秒、整块硬切到新流，无淡入淡出闪缩；录制中、三联屏下不可切换。
10. **赞赏/交流**：顶栏在「N 个直播」左侧点「赞赏/交流」，左右查看赞赏码与微信群码。
11. **ESC 关闭**：直播列表、大屏、对比预览均支持 ESC；赞赏/交流弹窗、「资源/设置」面板叠在大屏之上时按 ESC 也能优先关掉。
12. **资源/设置**：顶栏打开统一面板——「资源监控」看内存/HLS；「插件设置」调直播墙性能（加载/录制路数、清晰度四档等，改动即时生效，可一键还原）；「数据备份」导入/导出特别关心。

## 注意事项

- 使用前请确保已登录抖音账号
- 仅支持抖音网页版，不支持手机版
- 录制保存到浏览器默认下载目录，文件格式随编码而定：命中硬件 H.264 为 `.mp4`/`.mkv`，回退 VP8 为 `.webm`；录制过程中关闭/刷新页面会尝试保存已录内容
- 多路对比为多路不同直播流同时解码，对机器性能有一定要求；打开对比/大屏时已自动暂停后台直播墙、录制时优先用硬件编码以降低占用
- 如遇到问题请刷新页面或重新安装插件
- 连麦画面会自动调整以获得最佳观看体验
- 数据存储：特别关心、声音/音量、氛围词条等存在 `chrome.storage.local`，**在扩展中心「重新加载」不会丢**；但「移除插件再重新添加」会清空，重装前请先在「资源/设置」→「数据备份」导出特别关心
